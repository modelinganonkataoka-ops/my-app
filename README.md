# 🚀 わくわくスタディパーク (WakuWaku Study Park) Pro

Three.js による 3D キャラクターと一緒に楽しく学べる、小学生向けのデジタル＆プリント学習 Web アプリケーションです。

ブラウザ上でのインタラクティブなクイズ学習はもちろん、紙と鉛筆で勉強できるように**A4学習プリントの自動作成・印刷（PDF保存）機能**、**AI問題無限ジェネレーター**、**先生モード（オリジナル問題作成・CSV/JSONインポート・エクスポート）**、**AIサポートロボット「ロボまる」**を備えています。

---

## 🌟 主な特徴・機能一覧

### 1. 🎲 問題の正解位置の完全ランダム化
- 出題時（じっくり練習、Kahootバトル、まなびプリント）に選択肢が自動シャッフルされ、正解が「ア」「イ」「ウ」「エ」（Kahootでは赤・青・黄・緑）にランダムに配置されます。

### 2. 🤖 AI無限問題ジェネレーター ＆ 外部LLM連携
- **大容量ビルトイン問題データベース**:
  - 小学1年生〜小学6年生 × 5科目（国語・算数・理科・社会・英語）の高品質な問題を標準で450問以上収録。
- **ルールベースのアルゴリズム自動生成（APIキー不要・無料）**:
  - 算数の計算問題・文章題（繰り上がり・九九・小数・分数・割合・速さ・面積等）、国語の漢字・対義語・ことわざ、理科の天体・生物・実験、社会の都道府県・歴史人物・政治、英語の語彙・会話文を何千問でも無限に動的生成。
- **Gemini API 連携**:
  - Gemini APIキーを入力することで、自由な指定テーマ（例：「SDGs」「宇宙」「プログラミング」等）に沿った最新LLMによる問題をリアルタイム生成・追加可能。
- **ChatGPT / Claude 用プロンプト生成**:
  - 外部AIからワンクリックで問題を取り込めるプロンプト生成・クリップボードコピー機能つき。

### 3. ✏️ 先生モード（オリジナル問題作成 ＆ インポート/エクスポート）
- **オリジナル問題作成**:
  - 学年、科目、問題文、選択肢4つ、正解指定、解説、プリント用解答を自由に設定して保存。
  - 「AIに下書きを作ってもらう」ボタンで問題作成をアシスト。
- **エクスポート機能**:
  - `JSON形式`: 全問題または自作問題をJSONファイルとしてダウンロード。
  - `CSV形式（Excel対応）`: UTF-8 BOM付きCSVでExcel編集に対応。
- **インポート機能**:
  - ファイルからの読み込み（.json / .csv）に対応。
  - テキスト貼り付けによる一括インポートモーダルを完備。
  - 先生用のサンプルCSVひな形（テンプレート）のダウンロードが可能。
- **ローカル永続化**:
  - 作成・インポートされた問題はブラウザの `localStorage` に自動保存され、次回アクセス時も維持。自習・ゲーム・プリントのすべてに出題反映されます。

### 4. 🤖 AI相棒「ロボまる」学習サポート機能
- **💡 AIヒント**:
  - ロボまるが思考アニメーションを実行し、問題のポイント・解き方のヒントを優しく提示。
- **🎯 50:50（2択にする）**:
  - AIスキャンにより、不正解の選択肢を2つ消去してサポート。
- **💬 ロボまるAIチャット（相談室）**:
  - ロボまると対話できるチャットモーダル。勉強のコツや苦手科目の克服法、励ましのアドバイスを小学生向けに優しく返答。
- **🔊 AI音声読み上げ**:
  - Web Speech API による合成音声で、ロボまるが問題文やヒント、正解のセリフを可愛らしく読み上げ。
- **Three.js 3D アクション**:
  - 浮遊、思考モーション、指差しヒント、宙返りジャンプ、アンテナの発光エフェクト。

### 5. 🖨️ A4まなびプリント（5問 / 10問 完全対応）
- 出題数切り替え（5問ミニテスト / 10問しっかり練習）に対応。
- **10問選択時はA4用紙2枚（1〜5問、6〜10問）に自動分割**され、小学生がゆったり書き込める十分なスペースを確保。
- ページ番号インジケーター（1/2ページ、2/2ページ）つき。
- 「こたえ・かいせつシート」も10問分が美しく整理されて出力。
- ブラウザの印刷ダイアログ（Ctrl+P / ⌘+P）からそのままA4用紙に印刷またはPDF保存できます。

### 6. ⚡ Kahoot!ふう スピード対戦ゲームモード
- 4色のインパクトある選択肢（▲ 赤、◆ 青、● 黄、■ 緑）。
- 15秒のカウントダウンタイマー（スピードボーナス＆チクタク音）。
- 連続正解による「🔥 STREAK」コンボボーナスシステム。
- AIライバルたち（うさぎちゃん、くまごろう等）とリアルタイム対決。
- リーダーボード（順位表）＆ 表彰台（Podium 1st, 2nd, 3rd）演出。

## 💻 動作確認・ローカル実行

特別なビルド環境（Node/npmビルド等）は不要です。ブラウザでそのまま `index.html` を開くだけで動作します。

```bash
# Pythonの簡易HTTPサーバーで起動する場合
python3 -m http.server 8000
# ブラウザで http://localhost:8000 にアクセス
```
