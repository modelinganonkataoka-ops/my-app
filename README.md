# 🚀 わくわくスタディパーク (WakuWaku Study Park)

Three.js による 3D キャラクターと一緒に楽しく学べる、小学生向けのデジタル＆プリント学習 Web アプリケーション（MVP）です。

ブラウザ上でのインタラクティブなクイズ学習はもちろん、紙と鉛筆で勉強できるように**A4学習プリントの自動作成・印刷（PDF保存）機能**を備えています。

---

## 🌟 主な特徴

1. **学年設定（小学1年生〜小学6年生対応）**
   - いつでも学年を切り替え可能。
   - 学年に合わせた問題の難易度や、ふりがな・漢字の表記に対応。

2. **5科目完全対応**
   - 📕 **国語（こくご）**: 漢字、反対語、ことわざ、慣用句、古典など
   - 📐 **算数（さんすう）**: 計算、九九、図形・角度、小数・分数、割合など
   - 🔬 **理科（りか）**: 生き物・植物、磁石・電気、天体、人体、水溶液など
   - 🗾 **社会（しゃかい）**: 交通安全・地図記号、都道府県、産業、歴史・憲法など
   - 🔤 **英語（えいご）**: アルファベット、挨拶、身近な単語、日常表現など

3. **⚡ Kahoot!ふう スピード対戦ゲームモード（新機能！）**
   - 4色のインパクトある選択肢（▲ 赤、◆ 青、● 黄、■ 緑）。
   - 15秒のカウントダウンタイマー（スピードボーナス＆チクタク音）。
   - 連続正解による「🔥 STREAK」コンボボーナスシステム。
   - AIライバルたち（うさぎちゃん、くまごろう等）とリアルタイム対決。
   - ラウンドごとの「リーダーボード（順位表）」表示。
   - 最終結果の「表彰台（Podium 1st, 2nd, 3rd）」＆王冠・紙吹雪演出！

4. **Three.js による 3D キャラクター演出**
   - 相棒のロボットキャラクター「ロボまる」が画面内でふわふわ浮遊。
   - マウスやタップの動きに合わせて視線を追従。
   - 正解すると大ジャンプ＆360度宙返りし、星や花火（Confetti）でお祝い！
   - 不正解のときも優しく励ましてくれるリアクション。
   - 科目ごとに異なる3Dアイテム（本、ブロック、リング、地球儀など）が出現。

5. **Web Audio API による効果音システム**
   - 外部音声ファイルへの依存なし。ブラウザ上でリアルタイム合成される正解チャイム、カウントダウン音、ドラムロール、歓声ファンファーレ。
   - ワンタップでサウンド ON / OFF の切り替えが可能。

6. **紙でも学べる！A4学習プリント印刷機能（Print Stylesheet）**
   - 選択した学年・科目の問題を、学校の宿題やテストのような綺麗なA4プリント形式で生成。
   - 「名前・組・日付・得点」記入欄つき。
   - 保護者・先生向けの「こたえ・解説シート」も同時に出力可能。
   - `@media print` 最適化により、WebのUIを隠して用紙サイズ（A4）にぴったり印刷・PDF保存できます。

## 💻 動作確認・ローカル実行

特別なビルドツールは不要です。ブラウザでそのまま `index.html` を開くだけで動作します。

```bash
# Pythonの簡易HTTPサーバーで起動する場合
python3 -m http.server 8000
# http://localhost:8000 にアクセス
```

## 🌐 GitHub Pages による自動公開

本リポジトリには [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) が設定されています。
`main` ブランチにコミットを push すると、GitHub Actions が自動実行され GitHub Pages に公開されます。

### GitHub リポジトリでの確認手順:
1. リポジトリの **Settings** > **Pages** を開く。
2. **Build and deployment** の **Source** が `GitHub Actions` に設定されていることを確認してください。
3. push 完了後、Actions ワークフローが完了すると公開 URL が発行されます。
